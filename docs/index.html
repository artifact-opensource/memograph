MEMOGRAPH PROTOCOL — v0.2.0 / INSTITUTIONAL MEMORY

Memory is not a folder.
Memory is topology.

Three independent streams — Live, Project, Enterprise — that never merge physically but can assemble into temporary unified context. Every shard has a hash, an owner, a scope, and a lifecycle.

SHA256 SHARDS 3-DOMAIN ROUTING TOKEN-CAPPED GRAPH APPEND-ONLY AUDIT

The Three Memory Streams

Live Conversational

The present. Intent, decisions, constraints, working state. Shards have short lifetimes — some survive minutes, some are promoted to Project.

DOMAIN: LIVE

Project Memory

History, architecture, documents, data, agents. A project owns its identity and is not required to know other projects exist.

DOMAIN: PROJECT

Enterprise / Org

Policy, governance, standards, shared datasets, approval structures. Inherited by projects; never dumped globally.

DOMAIN: ENTERPRISE

The MemoGraph — Not One Database

Memory stops being a folder hierarchy when shards can reference other shards. A project decision points to the conversation that produced it; the conversation points to the research; the research points to the dataset; the dataset points to the model; the result points back to the decision.

Every relationship is addressable. The graph is traversed with a bounded token budget (knapsack-constrained) — context is an execution layer, memory is persistence. They never become the same thing.

Core Primitives

MemoryShard(content, owner, scope, domain, parent_hash, permissions)
  → compute_hash() → SHA256 identity

ContextRouter(query_context, weights={semantic:0.40, recency:0.25, authority:0.20, affinity:0.15})
  → score_shard() → permission + recency + authority + affinity

MemoGraph.add_shard() / assemble_context(scored_shards, max_tokens)
  → bounded traversal → temporary unified context

Dogfood Note — Gateway Integration

Memograph is configured as the exclusive context pool for this gateway, with main Hermes context preserved as a safe-mode fallback (never overwritten, only dormant). Every retrieval/store/promotion event writes to an append-only audit trail. If Memograph fails — file mutation error, storage corruption, graph traversal failure — the agent falls back to native context and logs the failure, rather than going offline.
